Calculadora

Uma calculadora matemática funcional com design moderno e interface em modo noturno. O usuário digita dois valores numéricos em campos de texto integrados aos estados do React. Abaixo, um painel gerado dinamicamente exibe os botões das quatro operações básicas (soma, subtração, multiplicação e divisão). Ao clicar em qualquer operador, o app valida os dados (evitando divisões por zero) e renderiza instantaneamente o resultado final em destaque na tela.

Card RPG

Card voltado para jogos de RPG que serve como um laboratório visual para testar o comportamento do Flexbox. Exibe dois cartões de atributos do mesmo personagem. O primeiro cartão organiza as informações de forma vertical (column), com a foto e os textos centralizados. O segundo cartão reorganiza os mesmos elementos de forma horizontal (row), alinhando a foto ao lado dos textos e dividindo as barras de vida (HP) e energia (Mana) lado a lado na mesma linha.

Loja de Eletrônicos

Sistema simples de gerenciamento e consulta de inventário de uma loja de eletrônicos/periféricos. Apresenta uma barra de pesquisa que filtra em tempo real a lista de mercadorias conforme o usuário digita. Ao tocar em qualquer produto cadastrado, o aplicativo abre uma janela de detalhes exibindo informações completas como preço, categoria, descrição longa e a quantidade disponível em estoque.

MangáApp

Estrutura focada na navegação de um aplicativo de leitura de mangás ou livros. Usa a biblioteca React Navigation para criar um menu de abas na parte inferior da tela. Tecnologias Utilizadas

  • React

    O React é uma biblioteca JavaScript criada pelo Facebook em 2011, projetada para o desenvolvimento de interfaces de usuário (UI) em aplicações web. Ele é amplamente utilizado devido à sua abordagem declarativa, eficiente e flexível, permitindo a criação de componentes reutilizáveis que facilitam a construção de interfaces complexas.

  • Expo

    Expo é uma plataforma open source que facilita o desenvolvimento, o build e o deploy de aplicativos mobile usando React Native, sem que você precise configurar manualmente o ambiente nativo do Android ou iOS.
